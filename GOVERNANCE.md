# Governance

ScaffoldScope is a maintainer-led open-source project. Satwik Sai Prakash Sahoo
is the current maintainer and release manager.

## Decisions

Routine fixes and compatible features are decided through review of their code,
tests, and documented trade-offs. Material changes to the experiment protocol,
evidence schemas, evaluator semantics, licensing, or governance start as a public
Protocol RFC issue before implementation.

The maintainer considers technical evidence, compatibility, security, maintenance
cost, and the project's measurement goals. Consensus is preferred but is not a
requirement; when significant objections remain, the decision and rationale are
recorded in the RFC.

## Releases and access

Only the maintainer may publish releases or change repository security settings.
Release tags are immutable. Repository access is granted narrowly and may be
removed when it is no longer needed.

Contributors gain responsibility through sustained, reviewable work and sound
handling of user data, credentials, and measurement claims. Additional
maintainers will be named publicly before receiving release authority.

## Project records

Issues and RFCs are the durable record for product and protocol decisions.
Vulnerability and conduct reports remain private as described in
[SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
